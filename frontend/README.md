# DabaPulse Frontend — Decision Theater

Interface React des six scènes du parcours décisionnel.

## Démarrage

```bash
cd frontend
npm install
npm run dev
```

Le dev server proxy `/api` vers `http://127.0.0.1:8000`.

## Scènes

1. `/` — Situation exécutive  
2. `/investigation` — Investigation du risque  
3. `/decision` — Decision Engine  
4. `/simulation` — What-if Simulator  
5. `/explication` — Explication IA  
6. `/horizon` — Growth Horizon  

## Build

```bash
npm run build
npm run typecheck
```
